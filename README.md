# 예술IN

뮤지컬·연극 등 공연 예술 분야의 지원자와 제작사를 연결하는 통합 오디션 플랫폼입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 `http://localhost:8080`에서 실행됩니다.

## 빌드

```bash
npm run build
```

프로덕션 빌드는 Nitro 기반의 서버 애플리케이션으로 생성됩니다.

```bash
npm run preview
```

미리보기 명령은 생성된 `.output/server/index.mjs`를 실행합니다.
